# Шахматы 2 на 2

Онлайн-шахматы вчетвером на одной доске: двое за белых, двое за чёрных, партнёры ходят по очереди (белые 1 → чёрные 1 → белые 2 → чёрные 2). Если за стороной один человек, он ходит за неё всегда, так что играть можно и вдвоём. Все остальные, кто открыл ссылку, смотрят партию.

Никаких зависимостей: нужен только Node.js 18 или новее. `npm install` не нужен.

## Запустить у себя

```
node server.js
```

Откройте http://localhost:3000, нажмите «Создать игру». Порт меняется переменной `PORT`.

## Дать ссылку друзьям прямо сейчас

Пока сервер запущен на вашем компьютере, откройте ещё одно окно терминала и сделайте туннель (любой из вариантов):

- **localhost.run** — без регистрации, есть почти везде:
  ```
  ssh -R 80:localhost:3000 nokey@localhost.run
  ```
  В ответ придёт адрес вида `https://xxxx.lhr.life`. Откройте его, создайте игру и скиньте ссылку комнаты друзьям.
- **Cloudflare** (нужен `cloudflared`): `cloudflared tunnel --url http://localhost:3000`
- **ngrok** (нужна регистрация): `ngrok http 3000`

Ссылка работает, пока включены компьютер, сервер и туннель.

## Постоянная ссылка (бесплатно)

**Render.com**
1. Залейте папку в репозиторий на GitHub.
2. На render.com: New → Web Service → выберите репозиторий.
3. Build command — оставить пустым, Start command — `node server.js`, план Free.
4. Через пару минут получите адрес `https://<имя>.onrender.com`.

Бесплатный сервер засыпает после 15 минут без посетителей: первое открытие ссылки займёт 30–60 секунд, потом всё работает быстро. При перезапуске сервера старые комнаты могут пропасть.

Любой VPS тоже подойдёт: `PORT=80 node server.js` (или через pm2 / systemd). Для https поставьте перед ним Caddy или nginx.

## Как устроено

- `server.js` — http-сервер, WebSocket (реализован вручную, без библиотек), комнаты. Сервер проверяет каждый ход и рассылает всем в комнате полное состояние.
- `public/rules.js` — шахматные правила: все ходы, рокировка, взятие на проходе, превращение, шах, мат, пат, ничьи (недостаток материала, троекратное повторение, 50 ходов). Один и тот же файл работает на сервере и в браузере.
- `public/index.html` — весь интерфейс одним файлом.
- `data/rooms.json` — комнаты сохраняются на диск и переживают перезапуск. Комнаты без активности дольше 48 часов удаляются.

Игрок опознаётся по случайному ключу в браузере, поэтому после перезагрузки страницы он возвращается на своё место.

## Тесты

```
npm test
```

`test/rules.test.js` сверяет генератор ходов с эталонными perft-числами и проверяет концовки. `test/play.test.js` поднимает сервер и играет партию четырьмя WebSocket-клиентами: очерёдность, мат, ход не в свою очередь, нелегальный ход, зритель, реванш, переподключение, сдача.
